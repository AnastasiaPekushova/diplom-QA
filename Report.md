Данный файл - отчетный документ по итогам тестирования

Автоматизированное тестирование приложения для покупки тура по определенной цене двумя способами (оплата картой и кредит по данным карты) проводилось для диагностики багов с целью недопущения утечки конфидициальных данных, а также потери прибыли и лояльности в будущем.

Были написаны 73 тест-кейса(по данным Allure-отчета), среди которых:
4 функциональных-теста (test_ui.py)
2 теста на работу с БД (test_sql.py)
10 тестов на валидацию с применением параметризации (test_validation.py)

В ходе тестирования было выявлено 16 багов, на которые были заведены баг-репорты в реппозитории GitHub  этого проекта во вкладке Issues

79.45% тестов пройдены успешно, 20.55% тестов не пройдены либо пропущены(в коде отмечены как xfail)
